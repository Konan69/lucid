Routines were removed. The Watch recipe uses its disposable Verify Pulse Integration and checks the delivered Feed card. The ordinary Conversation Feed recipe checks projection and lifecycle separately. Web is the primary surface. Phone native behavior requires its own device runs. Desktop has a separate Linux Electron recipe with explicit OS limits. Home's first-send handoff/retry and once-only arrival greeting, socket recovery, interactive display actions, question withdrawal and reminder delivery remain unproved entry points within the mapped features. Read reporting maps parked-Thread metadata updates, real offscreen model replies and bounded client reporting; failed-claim retry remains blocked. Settings maps empty saved knowledge, personal navigation groups, and public Integration catalog groups/search. Its populated knowledge, Company, authorization, and native subcases remain unproved. Library shelves, folders, rename/move, duplicate feedback and Ask Vivid also lack recipes; see apps/web/src/screen/Library.tsx and packages/client/state/src/library.ts. Projects, sharing and appearance remain additional entry points in main, and saved procedures are mapped only through teaching; extend this map before changing them, using production contracts and the actual client controls.
