Routines were removed. Watches and Feed replace that journey; they need a disposable external Integration. Web is the primary surface. Phone and desktop native behavior require their own device runs. Home’s first-send handoff/retry and once-only arrival greeting, parked-Thread revisits, socket recovery, interactive display actions, question withdrawal and reminder delivery remain unproved entry points within the mapped features. Library shelves, folders, rename/move, duplicate feedback and Ask Vivid also lack recipes; see apps/web/src/screen/Library.tsx and packages/client/state/src/library.ts. Projects, sharing, settings, appearance, saved skills, connections and notes remain additional entry points in main; extend this map before changing them, using production contracts and the actual client controls.
